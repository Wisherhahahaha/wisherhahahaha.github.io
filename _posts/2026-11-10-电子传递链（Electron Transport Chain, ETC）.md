## 二、线粒体结构：ETC 的发生场所

### 2.1 结构层次（由外向内）

| 结构 | 英文 | 特征 | 主要功能 |
|---|---|---|---|
| **外膜** | Outer mitochondrial membrane | 平滑，通透性较高（含孔蛋白） | 与细胞质相隔；物质进出屏障 |
| **膜间隙** | Intermembrane space | 外膜与内膜之间的腔隙 | **质子（H⁺）的蓄积场所**，pH 较低 |
| **内膜** | Inner mitochondrial membrane | 高度折叠，蛋白质含量极高，对离子不通透 | **电子传递链与 ATP 合酶所在地** |
| **嵴** | Cristae | 内膜向内折叠形成的片状/管状突起 | **极大增加内膜表面积**，容纳更多呼吸链复合体 |
| **基质** | Matrix | 内膜包被的内部液体 | 丙酮酸 → 乙酰CoA、TCA 循环、脂肪酸 β-氧化 |

### 2.2 关键定位结论

- **电子传递链发生在（内膜/嵴）上。**
- **丙酮酸氧化脱羧（丙酮酸 → 乙酰辅酶A）与克雷布斯循环（TCA）发生在基质中。**
- 嵴的折叠意义：**表面积 ↑ → 呼吸链复合体数量 ↑ → ATP 产能效率 ↑**。
- 膜间隙的意义：**质子被泵入此处，形成跨内膜的电化学梯度**。

> ⚠️ 视频口误：多处将"内膜（inner membrane）"说成"内质网（endoplasmic reticulum）"。二者完全不同，本讲语境下一律为**线粒体内膜**。

## 三、前导代谢回顾：电子从哪里来

### 3.1 三大阶段的电子产出

| 阶段 | 场所 | 反应概要 | NADH | FADH₂ | ATP（净） |
|---|---|---|---|---|---|
| **糖酵解** | 细胞质 | 葡萄糖（6C）→ 2 × 丙酮酸（3C） | 2 | 0 | +2 |
| **过渡反应（丙酮酸氧化脱羧）** | 线粒体基质 | 2 丙酮酸 → 2 乙酰辅酶A + 2 CO₂<br>酶：**丙酮酸脱氢酶复合体** | 2 | 0 | 0 |
| **克雷布斯循环（TCA）** | 线粒体基质 | 2 乙酰CoA 完全氧化 | **6** | **2** | +2（GTP） |
| **合计（每分子葡萄糖）** | — | — | **10** | **2** | 4 |

> 视频强调的"重要部分"：**TCA 循环本身产生 6 个 NADH**（不含过渡反应的 2 个、不含糖酵解的 2 个）。

### 3.2 丙酮酸进入线粒体

- 若**氧气存在**（有氧条件），丙酮酸经**特异性载体蛋白**主动转运进入**线粒体基质**。
- 在基质中由**丙酮酸脱氢酶复合体**催化 → **乙酰辅酶A**。

### 3.3 氢化物离子（Hydride ion, H⁻）——理解 NADH/FADH₂ 的关键

$$\mathrm{H^- \;=\; 1\,个质子(H^+) \;+\; 2\,个电子(e^-)}$$

- **NADH / FADH₂ 的本质作用：携带氢化物离子（即"质子 + 2 电子"）。**
- 视频用语："这两个家伙是**电子穿梭者**（electron shuttles）"——它们把电子从代谢反应运送到电子传递链。
- 到达呼吸链后：
  - **NADH → NAD⁺ + H⁻**（NADH 被氧化）
  - **FADH₂ → FAD + H⁻**（FADH₂ 被氧化）
  - 释放的 **2 个电子**进入传递链；**质子（H⁺）**则留在基质或被用于还原反应/形成梯度。

## 四、ETC 的三大核心原理

### 原理 1：电子沿氧化还原电位递增方向逐级传递

- 各组分按**标准还原电位（E°′）由负到正**排列。
- 电子自发从"低电位（易失电子）"流向"高电位（易得电子）"。
- 每一步都释放**自由能（ΔG = −nFΔE）**，能量逐步释放而非一次性爆发 → **高效捕获**。

### 原理 2：能量图模型（视频重点讲解）

视频以"能量（y 轴）× 反应进程（x 轴）"图解释每个复合体的工作机制：

1. 复合体处于**低能量水平**（稳定态）。
2. **接受电子** → 跃升至**高能量水平**（激发/不稳定态）。
3. "没有任何分子喜欢处于高能量水平" → **迅速把电子传给下一个组分**。
4. 传电子的同时**回落到低能量水平**，释放的能量**被耦合到质子泵**。

> 视频形象比喻：**"热土豆游戏"（game of hot potato）**——电子像烫手山芋，被一个组分一个组分地快速传下去，最后交给氧气。

### 原理 3：质子泵与"孔道"结构

- **只有部分复合体具有跨膜质子通道（视频称"孔"/port）**。
- 复合体在"高能 → 低能"回落过程中，构象变化打开孔道，将基质中的 **H⁺ 泵入膜间隙**。
- 泵质子方向：**线粒体基质 → 膜间隙**（内膜间隙）。

| 复合体 | 是否泵质子 | 视频描述 |
|---|---|---|
| 复合体 I | ✅ 是 | "他有一种特殊的孔"，泵出 H⁺ |
| 复合体 II | ❌ 否 | "他没有孔……没有蛋白质泵出质子的组件" |
| 复合体 III | ✅ 是 | "他有另一个通道在侧面……泵出质子到内膜间隙" |
| 复合体 IV | ✅ 是 | "我有一个小通道……从基质泵入膜间隙" |

## 五、电子载体与移动传递者

ETC 由 **4 个膜整合蛋白复合体** + **2 个可移动电子载体** 组成。

### 5.1 辅酶 Q（Coenzyme Q / CoQ / 泛醌 Ubiquinone）

| 项目 | 内容 |
|---|---|
| 别名 | 辅酶Q、泛醌（ubiquinone）、**辅酶Q10**（人体主要形式，Q10 指异戊二烯侧链含 10 个重复单元） |
| 化学本质 | **脂溶性醌类小分子，不是蛋白质** |
| 特殊地位 | **整条电子传递链中唯一不是蛋白质的组分** |
| 移动性 | 可在**内膜脂双层中自由扩散移动**（"他可以跑在前面"） |
| 功能 | 汇集**复合体 I 和复合体 II** 的电子，统一交给**复合体 III**（电子流的"汇合点"） |
| 三种氧化还原态 | 氧化态 **Q（泛醌）** → 半醌自由基 **Q·⁻（semiquinone）** → 还原态 **QH₂（泛醇 ubiquinol）** |
| 反应 | $\mathrm{Q + 2e^- + 2H^+ \rightarrow QH_2}$（QH₂ 同时携带 2 电子 + 2 质子） |

### 5.2 细胞色素 c（Cytochrome c, Cyt c）

| 项目 | 内容 |
|---|---|
| 化学本质 | **小型水溶性外周膜蛋白**，位于**内膜外侧（膜间隙面）** |
| 辅基 | **血红素（heme）**，中心为**铁原子**；以共价键连接蛋白 |
| 氧化还原 | $\mathrm{Fe^{3+} + e^- \rightleftharpoons Fe^{2+}}$，**一次只传递 1 个电子** |
| 移动性 | 可沿内膜表面滑动，在**复合体 III 与复合体 IV 之间**穿梭 |
| 功能 | 把电子从复合体 III 交给复合体 IV |

### 5.3 细胞色素家族的共同特征

- 本质是**含血红素辅基的蛋白**（"就像是血红素群，有色素成分"）。
- 中心金属为**铁（Fe）**；部分细胞色素氧化酶还含**铜（Cu）**。
- 铁在 **Fe³⁺（氧化态，高铁）** 与 **Fe²⁺（还原态，亚铁）** 之间可逆转换，实现**单电子传递**。

## 六、四大复合体逐个拆解

### 6.1 复合体 I

| 项目 | 内容 |
|---|---|
| **规范名称** | **NADH:泛醌氧化还原酶**（NADH:ubiquinone oxidoreductase） |
| **视频用名** | 复合体 I / **NADH 脱氢酶**（NADH dehydrogenase） |
| **命名规律** | 视频提示："每当你处理 NAD（H）时，总会有一个**脱氢酶**" |
| **电子供体** | NADH（来自糖酵解穿梭、丙酮酸脱氢、TCA） |
| **电子受体** | 辅酶 Q（泛醌） |
| **辅基与传递顺序** | **FMN（黄素单核苷酸）→ 一系列铁硫簇（Fe-S）→ CoQ** |
| **是否泵质子** | ✅ **是** |
| **结构特点** | 最大的复合体，L 形，横跨内膜；含质子泵孔道 |

**反应过程（视频逐步描述）：**

1. NADH 结合复合体 I，**被氧化为 NAD⁺**，释放氢化物离子（H⁻ = H⁺ + 2e⁻）。
2. **2 个电子交给 FMN**，FMN 被还原为 **FMNH₂**（还原型黄素单核苷酸）。
3. FMNH₂ 将电子依次传给**铁硫簇蛋白**（Fe-S，"传递到许多铁硫簇蛋白"，视频提示此细节在本讲不关键）。
4. 电子最终交给**辅酶 Q**，Q 被还原为 **QH₂**（还原型辅酶Q / 泛醇）。
5. 电子传递释放的能量 → 复合体 I **构象变化 → 打开孔道 → 将 H⁺ 从基质泵入膜间隙**。

**化学计量（视频 vs 教材）：**

| | 视频表述 | 教材标准值 |
|---|---|---|
| 泵出 H⁺ | "泵出一个质子" | **4 H⁺ / 2 e⁻** |

$$\mathrm{NADH + H^+ + Q + 4H^+_{(基质)} \rightarrow NAD^+ + QH_2 + 4H^+_{(膜间隙)}}$$

---

### 6.2 复合体 II

| 项目 | 内容 |
|---|---|
| **规范名称** | **琥珀酸脱氢酶**（Succinate dehydrogenase, SDH） |
| **视频用名** | 复合体 II /（口误）"苹果酸氢化酶" |
| **电子供体** | FADH₂（酶上共价结合的 FAD） |
| **电子受体** | 辅酶 Q |
| **辅基与传递顺序** | **FAD → 铁硫簇（Fe-S）→ CoQ** |
| **是否泵质子** | ❌ **否**（"他没有孔，没有泵出质子的蛋白质组件"） |
| **双重身份** | **既是 TCA 循环的酶，又是电子传递链的复合体**（唯一） |

**⚠️ 重要校正（视频此处有明显混淆）：**

- 视频说"你是否记得当你在克雷布斯循环中转化苹果酸为（草酰乙酸）的时候，它在做什么，它正在将 FAD 转化为 FADH₂"。
- **正确内容应为：**
  - TCA 中生成 **FADH₂** 的反应是：**琥珀酸 + FAD → 延胡索酸 + FADH₂**，催化酶为**琥珀酸脱氢酶 = 复合体 II**。
  - TCA 中"苹果酸 → 草酰乙酸"由**苹果酸脱氢酶**催化，使用 **NAD⁺/NADH**（生成 NADH），**与 FAD 无关，也不是复合体 II**。
- 视频"这不是一个严格监管的步骤，是可逆的"——这一点适用于**琥珀酸脱氢酶**：该反应**不是 TCA 的主要调控点**，因此电子流可较自由地双向调节。

**为何复合体 II 不泵质子？（教材补充）**

1. 它**不具备跨膜质子通道**（结构上只贴附于内膜基质侧）。
2. **琥珀酸/延胡索酸 → 泛醌** 的自由能落差**太小**，不足以驱动质子跨膜转运。
3. 因此，**经 FADH₂ 进入的电子绕过了复合体 I**，泵出的质子更少 → **每分子 FADH₂ 生成的 ATP 少于 NADH**。

---

### 6.3 复合体 III

| 项目 | 内容 |
|---|---|
| **规范名称** | **辅酶Q:细胞色素 c 氧化还原酶**（Coenzyme Q – cytochrome c oxidoreductase）；又称**细胞色素 bc₁ 复合体** |
| **视频用名** | 复合体 III / "辅酶Q–细胞色素 b 氧化还原酶" / 细胞色素 bc 复合体 |
| **电子供体** | QH₂（还原型辅酶Q / 泛醇） |
| **电子受体** | 细胞色素 c |
| **主要组分** | **细胞色素 b**（含血红素 b₅₆₂、b₅₆₆）、**Rieske 铁硫蛋白（2Fe-2S）**、**细胞色素 c₁** |
| **铁的氧化还原** | $\mathrm{Fe^{3+} + e^- \rightarrow Fe^{2+}}$（接受电子被还原）；$\mathrm{Fe^{2+} \rightarrow Fe^{3+} + e^-}$（给出电子被氧化） |
| **是否泵质子** | ✅ **是** |
| **工作机制** | **Q 循环（Q cycle）** |

**电子传递细节（视频描述）：**

1. QH₂ 结合复合体 III，将电子交给**细胞色素 b 中的铁**。
2. 铁由 **Fe³⁺ → Fe²⁺**（接受电子，被还原，进入高能态）。
3. Fe²⁺ 不稳定，"不想要这些电子"，将电子继续传递 → 回到 **Fe³⁺**，同时释放能量。
4. 电子经 **Rieske Fe-S → 细胞色素 c₁ → 细胞色素 c**。
5. 细胞色素 c 中的铁由 **Fe³⁺ → Fe²⁺**（被还原）。
6. 能量释放 → **打开侧向孔道 → 将 H⁺ 从基质泵入膜间隙**。

**化学计量（视频 vs 教材）：**

| | 视频表述 | 教材标准值 |
|---|---|---|
| 泵出 H⁺ | "泵出一个质子" | **4 H⁺ / 2 e⁻**（Q 循环：QH₂ 氧化的 2 个 H⁺ 直接释放 + 2 个 H⁺ 被泵送） |

---

### 6.4 复合体 IV

| 项目 | 内容 |
|---|---|
| **规范名称** | **细胞色素 c 氧化酶**（Cytochrome c oxidase） |
| **视频用名** | 复合体 IV / "氧化酶"（视频口误"复合体 for"） |
| **电子供体** | 细胞色素 c（还原态，Fe²⁺） |
| **电子受体** | **O₂（分子氧）——电子传递链的最终电子受体** |
| **组分** | **细胞色素 a + 细胞色素 a₃**（视频明确指出）；血红素铁 + **铜中心（Cu_A、Cu_B）** |
| **活性中心** | **血红素 a₃–Cu_B 双核中心**：O₂ 在此结合并被还原 |
| **是否泵质子** | ✅ **是** |
| **产物** | **水（H₂O）** |

**反应过程（视频描述）：**

1. 细胞色素 c（Fe²⁺）将电子交给**细胞色素 a/a₃ 中的铁**，铁的氧化态在 **Fe³⁺ ↔ Fe²⁺** 之间循环。
2. 铁接受电子 → **Fe³⁺ → Fe²⁺**（高能态，不稳定）。
3. 电子最终交给 **½ O₂**（原子氧）。
4. **½ O₂ + 2 H⁺ + 2 e⁻ → H₂O**（视频表述；按 2 电子计）。
5. 完整反应（4 电子，教材标准）：
$$\mathrm{O_2 + 4H^+ + 4e^- \rightarrow 2H_2O}$$
6. 电子传递释放能量 → 铁由 **Fe²⁺ 回到 Fe³⁺（低能态）** → **打开孔道，将 H⁺ 从基质泵入膜间隙**。

**关键概念：**

- **氧气是"最终电子受体"（terminal electron acceptor）**。
- 视频比喻："热土豆……然后给了氧气，他就接受了。他说好吧，我会接受这个土豆。"
- 意义：**若缺氧，电子无处可去 → 整条链"堵车" → NADH/FADH₂ 无法再氧化 → TCA 与糖酵解受阻 → 细胞转向无氧酵解**。这正是"有氧呼吸必须有氧"的根本原因。

## 七、全流程串讲（一图流）

### 7.1 电子流路径

**路径 A：NADH 通路（产 ATP 多）**

```
NADH
  │  （氧化为 NAD⁺，释放 H⁻）
  ▼
【复合体 I】NADH 脱氢酶
  FMN → FMNH₂ → Fe-S 铁硫簇   ← ★ 泵 H⁺
  │
  ▼
辅酶 Q（泛醌 Q → 泛醇 QH₂）  ← 脂溶性，膜内自由移动
  │
  ▼
【复合体 III】细胞色素 bc₁
  Cyt b (Fe³⁺↔Fe²⁺) → Rieske Fe-S → Cyt c₁   ← ★ 泵 H⁺
  │
  ▼
细胞色素 c（Fe³⁺↔Fe²⁺）  ← 水溶性外周蛋白，膜间隙侧移动
  │
  ▼
【复合体 IV】细胞色素 c 氧化酶
  Cyt a → Cyt a₃–Cu_B   ← ★ 泵 H⁺
  │
  ▼
½ O₂ + 2H⁺ + 2e⁻ → H₂O   （O₂ = 最终电子受体）
```

**路径 B：FADH₂ 通路（产 ATP 少，绕过复合体 I）**

```
琥珀酸 ──【复合体 II】琥珀酸脱氢酶──► FAD → FADH₂ → Fe-S
                                          │  ✘ 不泵 H⁺
                                          ▼
                                    辅酶 Q（QH₂）
                                          ▼
                            【复合体 III】★ 泵 H⁺
                                          ▼
                                    细胞色素 c
                                          ▼
                            【复合体 IV】★ 泵 H⁺
                                          ▼
                                    ½ O₂ → H₂O
```

### 7.2 完整"热土豆"传递链（视频原话概括）

> 复合体 I → 辅酶 Q → 辅酶 QH₂ → 细胞色素 b → 细胞色素 c → 细胞色素氧化酶（a + a₃）→ **氧气**

### 7.3 质子泵送位点总结

| 位点 | 复合体 | 泵 H⁺ | 视频表述 | 教材标准（每 2 e⁻） |
|---|---|---|---|---|
| 1 | 复合体 I（NADH 脱氢酶） | ✅ | "泵出一个质子" | **4 H⁺** |
| 2 | 复合体 II（琥珀酸脱氢酶） | ❌ | "没有孔，不泵质子" | 0 |
| 3 | 复合体 III（bc₁） | ✅ | "泵出一个质子" | **4 H⁺** |
| 4 | 复合体 IV（细胞色素 c 氧化酶） | ✅ | "泵出一个质子" | **2 H⁺** |
| **合计（NADH 路径）** | I + III + IV | — | — | **10 H⁺** |
| **合计（FADH₂ 路径）** | III + IV | — | — | **6 H⁺** |

## 八、质子梯度与化学渗透

### 8.1 梯度形成过程

1. 复合体 **I、III、IV** 在传递电子时，利用释放的能量把基质中的 **H⁺ 泵入膜间隙**。
2. 内膜对 H⁺ **不通透**（无自由扩散通道），质子无法自行回流。
3. 结果：**膜间隙 H⁺ 浓度显著升高，基质 H⁺ 浓度降低**。

### 8.2 视频给出的浓度数据

| 区域 | 质子浓度（视频） |
|---|---|
| 泵送前（基质与膜间隙大致相等） | ≈ **10⁻⁹ mM** |
| 泵送后 —— **膜间隙** | ≈ **10⁻⁷ mM** |
| 泵送后 —— **基质** | ≈ **10⁻⁹ mM**（维持低值） |

- 视频结论："膜间隙质子浓度**增加了两个数量级**（约 100 倍）"，从而**建立浓度梯度（concentration gradient）**。
- 视频明确说明：**梯度的用途将在后续内容中讨论**。

> 📌 **数据校正提示**：视频此处单位混用（10⁻⁹ M ≈ pH 9，与生理事实不符）。**教材标准值**：
> - 基质 pH ≈ **7.8–8.0**（[H⁺] ≈ 10⁻⁸ M）
> - 膜间隙 pH ≈ **7.0–7.4**（[H⁺] ≈ 10⁻⁷ M）
> - 即 **ΔpH ≈ 0.5–1.0 单位（约 3–10 倍浓度差）**，而非 100 倍。
> - 但**膜电位（Δψ ≈ −150 ~ −180 mV，基质侧为负）**才是质子动力势的主要贡献者。

### 8.3 质子动力势（Proton-Motive Force, PMF）

$$\Delta p = \Delta \psi - \frac{2.3RT}{F}\Delta \mathrm{pH}$$

- **组成**：① **化学梯度**（ΔpH，浓度差）② **电化学梯度**（Δψ，电荷差）
- **膜间隙**：H⁺ 多 → **正电、酸性**
- **基质**：H⁺ 少 → **负电、碱性**
- **去向**：H⁺ 只能通过 **ATP 合酶（复合体 V）** 的 F₀ 通道回流 → 驱动 **ADP + Pi → ATP**（**化学渗透学说，Chemiosmotic theory，Peter Mitchell**）。

> 本讲**未展开** ATP 合酶与 ATP 产量计算，属后续内容。

## 十、高频考点与记忆口诀

### 10.1 必背要点清单

1. **ETC 定位**：线粒体**内膜（嵴）**。
2. **电子传递顺序**：
   `NADH → 复合体 I（FMN→Fe-S）→ CoQ → 复合体 III（Cyt b→Fe-S→Cyt c₁）→ Cyt c → 复合体 IV（Cyt a→a₃）→ O₂ → H₂O`
3. **FADH₂ 入口**：**复合体 II**（琥珀酸脱氢酶），**绕过复合体 I**。
4. **唯一非蛋白组分**：**辅酶 Q（泛醌）**，脂溶性，膜内移动。
5. **唯一水溶性移动蛋白载体**：**细胞色素 c**，膜间隙侧移动。
6. **唯一同时属于 TCA 与 ETC 的酶**：**琥珀酸脱氢酶（复合体 II）**。
7. **泵质子的复合体**：**I、III、IV**；**不泵**：**II**。
8. **质子泵送方向**：**基质 → 膜间隙**。
9. **最终电子受体**：**O₂**；**产物**：**H₂O**。
10. **铁的存在形式**：**Fe³⁺（氧化态）↔ Fe²⁺（还原态）**，实现**单电子传递**。
11. **能量耦合逻辑**：电子"低能→高能→低能"回落时释放的能量，驱动质子泵 → 建立**电化学梯度** → 驱动 **ATP 合酶**。
12. **NADH vs FADH₂ 产能差异**：FADH₂ 少经复合体 I → 泵出的质子少 → **ATP 产量少**（约 1.5 vs 2.5）。

### 10.2 记忆口诀

- **传递顺序**：**「一Q三c四氧」**
  → 复合体 **一** → **Q** → 复合体 **三** → **c** → 复合体 **四** → **氧**
- **质子泵**：**「一二三四，二三不泵」** → 泵质子是 **I、III、IV**；**II 不泵**。
- **载体属性**：**「Q 是油，c 是水」** → CoQ 脂溶性在膜内跑，Cyt c 水溶性在膜面跑。
- **铁的变化**：**「得电子变二价（Fe²⁺），失电子变三价（Fe³⁺）」**。
- **热土豆游戏**：**电子是烫手山芋，氧气是最终接盘者**。

### 10.3 常见易错点

| 易错点 | 正确理解 |
|---|---|
| 以为复合体 II 也泵质子 | ❌ 复合体 II **无质子通道**，不泵质子 |
| 以为 FADH₂ 从复合体 I 进入 | ❌ FADH₂ 从**复合体 II** 进入 |
| 以为辅酶 Q 是蛋白质 | ❌ 它是**脂溶性小分子醌**，非蛋白 |
| 以为细胞色素 c 传递 2 个电子 | ❌ 它**一次只传 1 个电子**（Fe³⁺↔Fe²⁺） |
| 以为 O₂ 直接接受电子形成 OH⁻ | ✅ O₂ 接受 **4 e⁻ + 4 H⁺** 生成 **2 H₂O**（分步经 a₃–Cu_B 双核中心） |
| 以为电子传递直接合成 ATP | ❌ 电子传递只**建立质子梯度**；ATP 由 **ATP 合酶**合成（化学渗透偶联） |
| 以为基质 pH 更低 | ❌ **膜间隙 pH 更低（更酸）**，基质 pH 更高（更碱） |
| 把复合体 II 与苹果酸脱氢酶混为一谈 | ❌ 复合体 II = **琥珀酸脱氢酶**（用 FAD）；苹果酸脱氢酶用 **NAD⁺** |

## 十一、拓展补充（教材级细节）

### 11.1 还原电位序列（理解电子为何单向流动）

| 氧化还原对 | E°′ (V) |
|---|---|
| NAD⁺ / NADH | −0.32 |
| FMN / FMNH₂（复合体 I） | ≈ −0.30 |
| 泛醌 / 泛醇（Q / QH₂） | +0.04 |
| 细胞色素 b（Fe³⁺/Fe²⁺） | +0.07 |
| 细胞色素 c₁ | +0.22 |
| 细胞色素 c | +0.25 |
| 细胞色素 a | +0.29 |
| 细胞色素 a₃ | +0.55 |
| **½ O₂ / H₂O** | **+0.82** |

$$\Delta G^\circ{'} = -nF\Delta E^\circ{'}$$

- 电位差越大，释放自由能越多。
- **NADH → O₂ 总 ΔE°′ ≈ 1.14 V**，对应 **ΔG°′ ≈ −220 kJ/mol**（足以合成多个 ATP）。

### 11.2 ATP 产量的化学计量（现代 P/O 比）

| 电子供体 | 泵出 H⁺ | ATP 合酶耗 H⁺ | **净 ATP（P/O）** |
|---|---|---|---|
| NADH | 10（4+4+2） | ≈ 4 H⁺/ATP | **≈ 2.5 ATP** |
| FADH₂ | 6（4+2） | ≈ 4 H⁺/ATP | **≈ 1.5 ATP** |

**每分子葡萄糖有氧氧化总产 ATP（现代估算）：**

- 糖酵解：2 ATP（底物水平）+ 2 NADH（胞质，经穿梭）
- 丙酮酸脱氢：2 NADH
- TCA：2 GTP + 6 NADH + 2 FADH₂
- 氧化磷酸化：≈ 25 ATP（10 NADH × 2.5）+ 3 ATP（2 FADH₂ × 1.5）
- **总计 ≈ 30–32 ATP**（取决于胞质 NADH 采用何种穿梭）

### 11.3 呼吸链抑制剂与解偶联剂

| 物质 | 作用靶点 | 效应 |
|---|---|---|
| **鱼藤酮（Rotenone）**、阿米妥（巴比妥类）、杀粉蝶菌素 | **复合体 I** | 阻断 NADH 电子传递 |
| **丙二酸（Malonate）** | **复合体 II**（琥珀酸竞争性抑制） | 阻断琥珀酸氧化 |
| **抗霉素 A（Antimycin A）** | **复合体 III**（Cyt b） | 阻断 Q 循环 |
| **氰化物（CN⁻）、一氧化碳（CO）、叠氮化物（N₃⁻）、硫化氢** | **复合体 IV**（结合 a₃–Cu_B） | **阻断 O₂ 还原 → 细胞窒息死亡** |
| **寡霉素（Oligomycin）** | **ATP 合酶 F₀** | 阻断质子回流，间接抑制呼吸链 |
| **2,4-二硝基苯酚（DNP）、FCCP** | 内膜（**解偶联剂**） | 携带 H⁺ 自由穿膜 → **梯度消散，只产热不产 ATP** |
| **缬氨霉素（Valinomycin）** | 内膜（K⁺ 离子载体） | 破坏膜电位 |

### 11.4 活性氧（ROS）的产生

- 电子在**复合体 I（FMN 位点）**和**复合体 III（半醌 Q·⁻）**可能"泄漏"，直接把单个电子交给 O₂：
$$\mathrm{O_2 + e^- \rightarrow O_2^{\bullet-}\;（超氧阴离子）}$$
- 由 **超氧化物歧化酶（SOD）→ H₂O₂ → 过氧化氢酶/GPx → H₂O** 清除。
- 意义：氧化应激、衰老、缺血再灌注损伤的分子基础。

### 11.5 Q 循环（复合体 III 的精细机制）

- 每 **2 分子 QH₂** 被氧化：
  - 释放 **4 H⁺** 到膜间隙
  - 传递 **2 e⁻** 给 2 分子 Cyt c（经 Rieske Fe-S → Cyt c₁）
  - 另 **2 e⁻** 经 Cyt b（b_L → b_H）还原 1 分子 Q 为 QH₂（消耗基质 2 H⁺）
- 净结果：**4 H⁺ 出现在膜间隙 / 2 e⁻ 传给 Cyt c**。
- 这解释了为什么复合体 III 的 H⁺/e⁻ 比为 2:1。

## 十二、遗留问题与下一讲预告

### 12.1 本讲未解决的问题

视频结尾明确指出：

> "我们处理了 Krebs 循环中的 6 个 NADH、过渡步骤中的 2 个 NADH、TCA 中的 2 个 FADH₂，但**我们还没有考虑到（糖酵解产生的）NADH**。"

**核心矛盾：**

- 糖酵解在**细胞质**中产生 **2 分子 NADH**。
- **NADH 不能自由穿过线粒体内膜**（内膜对 NADH/NAD⁺ 不通透）。
- "它必须有一个特殊的、显然复杂的方式才能进入，然后释放那些电子。"

### 12.2 下一讲主题

**NADH 如何进入线粒体并行使功能** —— 即**电子穿梭系统（electron shuttle）**：

| 穿梭系统 | 主要组织 | 机制要点 | 产能结果 |
|---|---|---|---|
| **苹果酸–天冬氨酸穿梭**<br>（Malate–aspartate shuttle） | 心、肝、肾 | 胞质 NADH 还原草酰乙酸 → 苹果酸 → 进入基质 → 重新生成 NADH | 电子以 **NADH** 形式进入 → **≈ 2.5 ATP/NADH**（效率高） |
| **甘油-3-磷酸穿梭**<br>（Glycerol-3-phosphate shuttle） | 骨骼肌、脑 | 胞质 NADH 还原 DHAP → 甘油-3-磷酸 → 由**膜结合的 FAD 依赖甘油-3-磷酸脱氢酶**接受电子 → 直接交给 **CoQ** | 电子以 **FADH₂** 形式进入 → **≈ 1.5 ATP/NADH**（效率低，但速度快） |
